# Тема: Версіонування коду за допомогою Git

Цей репозиторій містить матеріали з вивчення операційної системи Linux та основи роботи з системами контролю версій (Git).

## Основні команди Git:
- `git init` — ініціалізація нового репозиторію.
- `git clone <url>` — клонування віддаленого репозиторію.
- `git add .` — додавання змін до індексу.
- `git commit -m "коментар"` — фіксація збережених змін.
- `git push origin main` — відправка змін у віддалений репозиторій.
