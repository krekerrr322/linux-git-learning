Основи операційної системи GNU/Linux

Навчальний матеріал та корисні команди CLI

1. Коротка інформація про ОС GNU/Linux

GNU/Linux — це сімейство вільних та відкритих Unix-подібних операційних систем, побудованих на базі ядра Linux та інструментів проекту GNU.

Ключові переваги:

  • Відкритий вихідний код (Open Source): будь-хто може переглядати, змінювати та розповсюджувати код.
  • Безпека та стабільність: розрахована на багатокористувацьку роботу з чітким розмежуванням прав доступу.
  • Гнучкість: використовується всюди — від мікроконтролерів і смартфонів (Android) до суперкомп'ютерів і серверів.

2. Популярні дистрибутиви Linux

  • Ubuntu: найпопулярніший дистрибутив для початківців та серверів на базі Debian.
  • Debian: стабільний дистрибутив із великою спільнотою, еталон надійності.
  • Fedora: дистрибутив із найновішими версіями ПЗ, виступає тестовим майданчиком для Red Hat.
  • Arch Linux: дистрибутив за принципом KISS ("Keep It Simple, Stupid") для досвідчених користувачів.
  • Linux Mint: зручна система зі звичним інтерфейсом для тих, хто переходить з Windows.
  • Manjaro: дружній до користувача дистрибутив на базі Arch Linux.

3. Основні команди Linux CLI

Команда Опис Приклад використання
pwd Виведе поточний робочий каталог pwd
ls Покаже вміст каталогу ls -la
cd Змінить поточний каталог cd /var/log
echo Виведе текст або значення змінної echo "Hello Linux"
touch Створить порожній файл або оновить час модифікації touch file.txt
mkdir Створить новий каталог mkdir new_folder
cp Скопіює файл або каталог cp file.txt /tmp/
mv Перемістить або перейменує файл/каталог mv old.txt new.txt
rm Видалить файл або каталог rm -rf my_folder
history Покаже історію виконаних команд history | tail -n 10

4. BASH-скрипт: Імітація авторизації

Нижче наведено скрипт auth.sh, який запитує логін та пароль у текстовому режимі:

#!/bin/bash

# Задані правильні облікові дані
VALID_USER="admin"
VALID_PASS="secret123"

echo "===================================="
echo "    Вітаємо у системі Linux CLI"
echo "===================================="

# Запит логіна
read -p "Введіть логін: " username

# Запит пароля без відображення на екрані (-s)
read -sp "Введіть пароль: " password
echo ""

# Перевірка авторизації
if [[ "$username" == "$VALID_USER" && "$password" == "$VALID_PASS" ]]; then
    echo "------------------------------------"
    echo "Успіх: Авторизацію пройдено! Вітаємо, $username."
    echo "Поточна дата: $(date)"
    echo "Ваш каталог: $HOME"
    echo "------------------------------------"
else
    echo "------------------------------------"
    echo "Помилка: Невірний логін або пароль!"
    echo "Доступ заборонено."
    echo "------------------------------------"
fi
