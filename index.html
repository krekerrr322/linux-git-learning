💻 1. Архітектура та Особливості GNU/Linux

GNU/Linux — це сімейство вільних Unix-подібних операційних систем, що базуються на ядрі Linux та наборі інструментів проектом GNU.

Ядро (Kernel)

Управляє апаратним забезпеченням: пам'яттю, процесором, пристроями введення/виведення.

Shell (Оболонка)

Командний інтерпретатор (напр., Bash, Zsh), що приймає команди від користувача.

Системні утиліти

Програми GNU для управління файлами, мережею, процесів та безпекою.

📦 2. Класифікація Дистрибутивів

Ubuntu / Debian

Найкращий вибір для серверів та початківців. Використовує пакетний менеджер apt.

Fedora / RHEL

Орієнтовані на інновації та корпоративний сектор. Використовують dnf / rpm.

Arch Linux / Manjaro

Системи з Rolling-release оновленнями для досвідчених користувачів (пакетний менеджер pacman).

📜 5. BASH-Скрипт Авторизації

Нижче наведено код скрипту auth.sh з логікою перевірки облікових даних:

#!/bin/bash

# Змінні авторизації
VALID_USER="admin"
VALID_PASS="secret123"

echo "===================================="
echo "    Система Авторизації Linux CLI"
echo "===================================="

read -p "Введіть логін: " username
read -sp "Введіть пароль: " password
echo ""

if [[ "$username" == "$VALID_USER" && "$password" == "$VALID_PASS" ]]; then
    echo "✅ Успіх! Вітаємо, $username."
    echo "Дата входу: $(date)"
else
    echo "❌ Помилка: Невірний логін або пароль!"
fi
